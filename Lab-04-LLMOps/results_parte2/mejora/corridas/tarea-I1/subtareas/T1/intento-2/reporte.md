# Tarea I1 — Resumen estadístico de latencias

## Parte 1 — Resumen

Datos registrados (ms): 120, 135, 128, 150, 142, 138, 160, 127 (n = 8)

| Métrica | Valor |
|---|---|
| Media | 137.50 ms |
| Desviación estándar muestral (n − 1) | 13.07 ms |
| Error estándar de la media | 4.62 ms |

Fórmulas usadas:
- media = (1/n) * sum(x_i)
- s = sqrt( sum((x_i - media)^2) / (n - 1) )
- EEM = s / sqrt(n)
